# Chappie role-reply model card

## Model

- Base: `jhu-clsp/mmBERT-base` (ModernBERT, 307M)
- Task: pairwise group-chat role matching — which observer avatar should reply
- Input: observer/owner role+department, members, recent group messages, trigger message
- Output: reply logit per candidate + a silence candidate
- Training: 8 epochs, max_length 576, Apple MPS
- Runtime: int8 ONNX via `classifier` `/rank`, `CLASSIFIER_MAX_LEN=576`

## Data

All train/val/test samples are generated by a large model; no real chat and no G1001.

| split | groups | samples | reply groups | silent groups |
| ----- | ------ | ------- | ------------ | ------------- |
| train | 120    | 462     | 60           | 60            |
| val   | 40     | 153     | 20           | 20            |
| test  | 60     | 230     | 30           | 30            |

Data + manifest are on `main` under `training/data/llm_role/`.

## Evaluation (real `/rank`, int8)

| split | reply recall | silent false wake | top1 | balanced acc |
| ----- | ------------ | ----------------- | ---- | ------------ |
| val   | 100%         | 0%                | 100% | 100%         |
| test  | 96.7%        | 0%                | 100% | 98.3%        |

Runtime margin: `-5.691539` (`classifier/model/margin.json`).

**Important:** Python training tokenizer and Rust classifier tokenizer encode slightly differently.
Always use the margin calibrated through the real `/rank` service, not the fp32
`training/out/mmbert-pairwise-llm/margin.json`.

## Artifacts

- `classifier/model/model.onnx` — int8 ONNX runtime model (~296MB)
- `classifier/model/tokenizer.json` — runtime tokenizer
- `classifier/model/labels.json`, `margin.json`
- `ai/src/models/linear-pairwise.json` — CPU linear model (current 957MB server)
- `training/out/linear-pairwise-llm.json` — linear model + metrics
- `MODEL_CARD.md`

Training weights (`model.safetensors`) and training data are intentionally **not**
included in this release. Keep them in local/artifact storage if retraining/export is needed.

## Runtime

```bash
AI_ROLE_MODEL=mmbert
AI_ROLE_MATCH=true
CLASSIFIER_BASE_URL=http://127.0.0.1:7010
CLASSIFIER_TIMEOUT_MS=12000
CLASSIFIER_RANK_MIN_MARGIN=-5.691539
```

`/rank` failure falls back to the role keyword rule. Pure notices are gated before `/rank`.
Linear model can be selected with `AI_ROLE_MODEL=linear`.

## Storage note

This release stores only deployable artifacts. Training weights and training data are
not included. The compatible 957MB server runs the linear model; the mmBERT classifier
needs >=1.8GB RAM and `CLASSIFIER_BASE_URL` / `CLASSIFIER_RANK_MIN_MARGIN`.
